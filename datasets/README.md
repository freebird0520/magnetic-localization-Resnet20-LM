# 数据集说明

## 格式

每个样本占 **16 行**，对应 4×4 传感器阵列的 16 个测点。每列以空格分隔：

```
<sensor_x> <sensor_y> <sensor_z> <pos_x> <pos_y> <pos_z> <ori_x> <ori_y> <ori_z> <Bx> <By> <Bz>
```

| 字段 | 说明 |
|------|------|
| `sensor_x`, `sensor_y`, `sensor_z` | 该测点的传感器平面坐标 (mm) |
| `pos_x`, `pos_y`, `pos_z` | 磁体位置 (mm)，16 行中相同 |
| `ori_x`, `ori_y`, `ori_z` | 磁体姿态欧拉角 (°)，16 行中相同 |
| `Bx`, `By`, `Bz` | 该测点实测磁场分量 (T)，因传感器位置而异 |

- 文件**首行为表头**，加载时自动跳过；

## 传感器阵列

4×4 平面阵列，间距 60 mm，位于 z = 0 平面：

```
(-90, 90)  (-30, 90)  (30, 90)  (90, 90)
(-90, 30)  (-30, 30)  (30, 30)  (90, 30)
(-90,-30)  (-30,-30)  (30,-30)  (90,-30)
(-90,-90)  (-30,-90)  (30,-90)  (90,-90)
```

具体坐标见 `config.py` 中的 `sensor_positions`。

## 预处理

加载时自动执行：
1. 解析 16 行 → 组装为 `(3, 4, 4)` 磁场图（Bx/By/Bz 三通道）；
2. **zero-padding** 为 `(3, 8, 8)`（上下左右各 pad 2 个零），适配 ResNet20 输入；
3. 可选注入高斯噪声（`noise_std > 0` 时）。

## 数据集结构

 `parameter.txt` 描述了对应 `dataset.txt` 磁体空间位置与欧拉角的采样组合，每份`dataset.txt`包含了3150份磁体位姿组合数；

在 `config.py` 中通过 `data_files` 字段配置使用哪些文件进行网络训练。

提供仿真模型 `magnet.mph` ，可使用`COMSOL Multiphysics®`仿真软件完成数据复现与扩充。
